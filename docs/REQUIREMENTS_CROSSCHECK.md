# 과제 요구사항 및 개선안 교차 확인

작성일: 2026-10-20. 과제 안내 PDF의 실제 페이지 번호를 사용한다. PDF 원문은 저장소에 배포하지 않는다.

## 개선 우선순위를 정한 근거

- 대상 누락/미등록 요청의 인증 서비스 대체: 각 3/3 재현. 대상 확인 기능의 직접 근거이다.
- 복수 대상 중 캐시 서비스 누락: 3/3 재현. 계획의 대상 집합을 검증할 필요가 있다.
- 미조회 로그의 분석 완료 표현: 결제 요청 3/3 재현. 형식 검사만으로 부족하다.
- 후속 문맥 문제와 장기 생성은 보조 검사로 확인했고 3/3 재현이라고 기재하지 않는다.
- 단일 결제/게이트웨이의 대상·매뉴얼 선택은 각 3/3 성공했다. 따라서 의미 검색 고도화만 우선하지 않고, 더 직접 재현된 대상/답변 오류부터 개선한다.

## 해석의 범위

개선 두 묶음이 과제 1번의 범위 안에 있고 평가 근거를 만들기 적합하다는 판단이다. 강사의 사전 승인이나 점수를 보장하는 판단은 아니다. RAG나 LLM 평가자를 새로 붙이지 않았는데 구현했다고 기재하지 않는다. 실제 구현 후 코드·응답·측정값을 설명할 수 있어야 한다.
