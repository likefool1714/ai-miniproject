총 300초는 목표다. 실제로 연습해 시간을 조정한다.
코드는 실제 파일에서 핵심 부분을 발췌했으며 한 함수 전체를 보여 주는 것이 아니다.
4·5·8장은 실제 브라우저 채팅 스크린샷이다. 4·5장은 같은 질문·관측값과 장애→정상 순서를 사용했다. 관측 ID·시각은 별도 실행이고, 이번 화면 비교는 버전별 한 번이다. 7장의 과거 5단계×3회 및 오늘 별도 API 검증과 합산하지 않는다.
복구 재점검·이력·보고서는 모델 생성 없이 코드로 처리한다. 원본은 실제 Ollama 생성이며 추론 속도 비교로 설명하지 않는다.
[오늘의 검증 조건·원문·화면](../results/bugfix-2026-10-21/README.md)을 참고한다.
원본/개선 비교는 로컬 Ollama·고정 MCP 입력이며 실제 제공 API 검사는 별도의 기능 호환 확인이다.
LangSmith 실제 추적은 미검증이다. 실제 PowerPoint 앱에서 열어 검사한 것으로 설명하지 않는다.
