# 발표 7장 구성안

현재는 구성 초안이다. 최종 PPT는 개선 구현과 실측 후 실제 코드·화면·수치를 넣어 작성한다.

| 장 | 제목 | 내용 |
|---|---|---|
| 1 | 문제와 목표 | 제공 운영 장애 대응 에이전트, 과제 1번, 두 개선 묶음 |
| 2 | 개선 전 재현 | 대상 임의 대체/복수 누락/미조회 로그 분석 표현, 기준 SHA와 입력 |
| 3 | 개선 A: 조사 대상 검증 | 대상 검사 → 확인 상태 → 명시 대상 집합 대조 → MCP 조회 흐름 |
| 4 | 개선 B: 근거 기반 답변 | 관측/추정/권고 구분, 수치·출처 검사, 재작성/중단 상태 |
| 5 | Before/After | 같은 입력/모델/스냅샷의 오류 건수·분자/분모·지연, 실패 사례 |
| 6 | 한계·트레이드오프 | 확인 턴 증가, 자연어 검사 범위, 재작성 지연, 출력 제한 |
| 7 | 직접 기여와 다음 개선 | 제공/직접 구현 구분, 재현 방법, RAG 등 후속 후보 |

약 5분 동안 변경 지점과 요청 한 건의 흐름으로 설명한다. 개선 전 기록과 After가 아직 없는 상태를 구분하고, 평가 결과가 기대와 다르면 실패와 원인을 그대로 제시한다.
