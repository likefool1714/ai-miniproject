# 한계·트레이드오프

| 선택 | 이점 | 한계 |
|---|---|---|
| 여러 신호 함께 판정 | CPU만 보고 복구 오판 억제 | 오래된 알림 하나로 보류 가능 |
| 5초 간격 정상 2회 | 단발 정상·중복 조회 방지 | 확인 지연, 관측 사이 정상 보장 못함 |
| 300초 유효시간 | 오래된 자료 사용 방지 | 느린·드문 조사에서 보류 증가 |
| 코드 기반 복구 | 재현 가능, LLM 호출 감소 | 복잡한 원인·사용자 결제 성공 미확인 |
| SQLite | 재시작 후 유지 | 저장 비용, 보관·삭제·권한 정책 미구현 |
| 고정 시나리오 | 재현 가능 | 합성 편향, 실제 장애 대표 못함 |

기준은 교육용 정책이며 실제 SLO가 아니다.
명령 해석은 제한된 표현을 지원한다. 자동 조치·주기 감시·운영 배포는 제외한다.
기존 LLM 진단의 모든 사실 오류를 해결한 것은 아니다.
원본에 없던 기능의 지원 여부와 자연어 의미 정확도는 구분해 평가한다.
