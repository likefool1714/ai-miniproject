# 오늘 마감·내일 오전 이해와 발표 연습

기준일: 2026-10-21. 사용자 일정은 **내일 10/22 오후 1시 발표**, 오전 9시~오후 1시는 이해·연습 시간이다.
과제 안내의 제출 마감과 실제 발표 시각은 구분해 최종 제출 여부도 확인한다.

## 오늘 마무리할 범위

1. 새 기능 후보 추가는 중단하고 이미 등록한 기능을 최종 범위로 고정한다.
2. 제공 키·접속 주소·허용 모델을 설정한 뒤 실제 API 일반 진단과 후속 재점검·이력·보고서를 확인한다.
3. 결과 원문과 화면을 저장하고 README에 실제 확인 범위·미완료 항목을 반영한다.
4. 그 결과를 반영해 최종 5분 PPT·발표 대본·필요한 PDF를 한 번 완성하고 슬라이드 화면을 검사한다.
5. 저장소·재현 명령·제출 링크를 점검한다. 발표 시 네트워크가 안 되어도 보여 줄 수 있도록 검증한 화면과 원문을 보존한다.

현재 로컬 제품 구현·검증은 완료, API 실제 확인과 최종 발표 파일은 대기다.
키가 없는 동안 API 테스트 완료로 표시하지 않는다. 키 입력이 끝나면 [API 확인 절차](API_VERIFICATION.md)를 진행한다.
