# 진행 계획 등록 초안

아래 내용은 등록 양식에 옮길 초안입니다. 외부 Google Spread에는 아직 등록하지 않았습니다.

## 선택 과제

1번 - Base Agent 기능 개선/추가

## 주제

대상 서비스 확인과 근거 기반 런북 검색을 통한 운영 장애 대응 에이전트 개선

## 개선 포인트

1. 대상 서비스가 없거나 등록되지 않은 요청을 특정 서비스로 임의 처리하는 기본값을 제거하고, 사용자 확인 후 모니터링 조사를 진행한다.
2. 영어 키워드 기반 incident_type 분류를 로컬 임베딩을 활용한 런북 의미 검색으로 개선하고, 검색된 대응 매뉴얼을 근거로 응답한다.
3. 동일한 평가 입력으로 개선 전후의 대상 처리 정확도, 런북 검색 정확도, 지연시간을 측정하고 실패 사례 및 트레이드오프를 정리한다.

## 진행 계획

Day1: 제공 코드 분석 및 기준 버전 저장, 평가 입력 확정, 대상 서비스 확인 기능 구현.
Day2: 런북 검색 및 그래프 연동, Ollama 실모델 검증, 제공 API 호환성 확인, Before/After 비교, 보고서 및 발표 자료 작성.
Day3 13시 이전: 최종 재현 및 문서/저장소 접근 확인 후 제출.

## 적용 기술

기존 FastAPI/Vue/LangGraph/MCP/SQLite 구조를 활용한다. 새로 대상 검증 분기, 확인 상태 관리, 로컬 임베딩 검색, 정답 기반 평가를 추가한다. LangSmith는 실제 키/추적 설정을 연결하여 확인한 경우에만 적용 결과를 기재한다.

## 기대 효과 및 범위

잘못된 서비스 조사와 증상에 맞지 않는 매뉴얼 선택을 줄이는 것을 목표로 한다. 효과는 동일 평가셋의 실측 결과로 확인한다. 실제 서비스 재시작/롤백 등 운영 조치는 실행하지 않으며, 6개 샘플 런북과 샘플 모니터링 데이터를 대상으로 한다.
