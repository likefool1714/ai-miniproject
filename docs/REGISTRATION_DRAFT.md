# 등록 내용

선택 과제: 1번 — 기존 운영 장애 대응 에이전트 개선/추가

## 개선 사항

- 이전·현재 상태 비교로 개선·악화 설명
- CPU·메모리·상태·알림을 종합해 복구·부분 회복·장애 지속·판단 보류 구분
- 정상 한 번으로 확정하지 않고 연속 관측 확인
- “다시 확인해줘”, “복구됐어?”를 이전 조사 서비스와 연결
- 기록이 없거나 오래되면 비교·판정 한계 표시

## 기능 추가

- 서비스별 조사 시각·상태·CPU·메모리·알림 저장·조회
- 수치 변화량과 알림 발생·해소 내역
- 사용자 요청 시 최신 자료 재조회·복구 확인
- 복구 확인 이후 이상이 관측되면 재발 안내
- 근거·상태 변화·복구 판단의 Markdown 보고서

제공 샘플·합성 시나리오 범위다. 실제 완료 상태는 README에서 구분한다.
