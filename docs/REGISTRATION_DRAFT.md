# 진행 계획 등록 요약

## 선택 과제

1번 - Base AI Agent 기능 개선/추가

## 주제

조사 대상 검증과 근거 기반 응답 검증을 통한 운영 장애 대응 에이전트 개선

## 개선 내용

1. 대상 서비스 누락/미등록 시 임의의 서비스를 조회하지 않고 사용자에게 확인한다. 복수 대상의 조사 누락을 방지하고 확인 대화에서 원래 증상과 대상을 유지한다.
2. 답변의 관측 사실/분석/권장 조치를 구분하고, 수집값과 수치·조회 출처를 대조한다. 검증 실패와 장시간 생성 시 재작성 한도·종료 상태·오류 안내를 제공한다.
3. 같은 입력·모델·모니터링 스냅샷으로 개선 전후의 잘못된 조회 수, 조사 대상 누락, 근거 오류 및 지연시간을 비교한다.

## 현재 진행

Ollama 기본 모델로 원본을 6종 시나리오 각 3회, 총 18회 실행했다. 대상 임의 대체·복수 대상 누락·미조회 로그 분석 완료 표현을 재현했다. 개선 기능은 아직 구현 전이다.

## 적용 기술과 범위

제공 FastAPI/Vue/LangGraph/MCP/SQLite/의존성 주입을 활용하고, 대상 검증·확인 상태·응답 검증 모듈과 검사를 추가한다. RAG는 후속 후보이며 현재 적용 기술로 주장하지 않는다. 실제 인프라 제어는 수행하지 않는다.
