기존 8100/8600 서비스와 이력은 유지하고, 별도 8124 백엔드·8624 웹 프록시·별도 SQLite DB를 사용했다.
제품 모델 어댑터·LangGraph·실제 stdio MCP·웹 프록시를 그대로 사용했다. 모델 호출 결과나 모니터링 공급자를 대체하지 않았다. 설정된 `recovery-demo` 자체는 합성 모니터링이다.

## 범위와 한계

- 현재 키로 실제 OpenAI API 연결과 선택한 기능 흐름이 작동함을 확인했다. 전체 진단 정확도나 무오류를 보장하지 않는다.
- 모니터링은 합성 데이터다. 실제 결제 성공·운영 서버 복구·근본 원인 제거를 검증하지 않았다.
- SSE는 웹 진행 이벤트 전달 검사다. 모델 API 자체의 토큰 스트리밍(stream=True)을 새로 구현·검증한 것은 아니다.
- LangSmith 추적은 false이며 이번 검증에도 포함하지 않았다.
- 기존 77개 회귀 검사는 이전 기록이며 이번 API 검사에 합산하지 않았다. 이번에 77개를 다시 실행한 것은 아니다.
- 기존 앱의 이전 프로세스 설정을 이번 키 검사 근거로 사용하지 않았다. 현재 키를 새로 읽은 전용 서버에서 검증했다.
