## 실행 결과

- 전체 Python 검사 91개 OK, 51.477초. 기존 77개와 신규 14개이며 단위·통합·회귀 검사를 포함한다. 테스트 파일은 6개다.
- 프론트엔드 동작 검사 4그룹 통과. 실제 API와 별도다.
- 수정본 실제 API 진단 4건 모두 근거 검증 통과, ModelFallback 없음. 원격 호출 14건 모두 HTTP 200, 현재 .env 키 일치 확인. 총 9,351토큰 사용 기록이다.

- 원격 호출 14건에는 진단 내부의 분류·계획·선택적 분석·작성 호출이 포함된다. 진단 건수와 다른 단위다.
- 장시간 경계는 실제 6분 대기 대신 주입한 시계로 재현했다. 실제 운영 장시간 부하 검사가 아니다.

## 보존한 보호 조건과 한계

현재 관측이 300초보다 오래되면 계속 판단 보류한다. 정상 관측 사이 300초 초과 공백이나 조회 실패는 연속 집계를 끊는다. 과거 장애는 3600초·최근 최대500건 범위로 제한한다. 이력·보고서 표는 기존 정책 범위를 따른다.
시나리오의 새 단계 시각만 수정했으며, 마지막 동일 관측의 시각을 계속 갱신해 신선한 것처럼 만들지 않았다.
진단 출력은 현재의 구조화된 설명이다. '보고서 형식'을 별도 파일 출력 서식으로 새 구현한 것은 아니며, 자동 파일 내보내기로 오분류하지 않도록 수정했다.
자연어 분기는 제한된 규칙이다. 복합·부정·새 표현 전체를 해결했다는 주장은 하지 않는다. 실제 로그 조회·원인 확정·서비스 조치는 수행하지 않는다.
